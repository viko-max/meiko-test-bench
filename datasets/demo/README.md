# 自写示例题

运行 `npm run demo`。六道自写题覆盖五个学科，包含单选、带单位的数值题、原图、共享材料和带小问的主观题。题面和图表位于 `public/`，评分依据位于 `scoring/`。两道降雨题各自携带同一份公开材料，因此可独立作答。

1. 输入 `/import`，依次确认预填路径、默认题集标识和版本。用 ↑↓ 选择题目，按 `v` 核对源材料与模型题面。选到 `demo-figure` 时可按 `i` 查看图表。按 Esc 返回预览，再按 Enter 入库。之前已入库时可跳到下一步。
2. 输入 `/run`，选择示例题集，检查六题均可运行。依次确认提供方和模型后，保持默认双模式并开始。工具模式在加速度题实际调用受限 calculate 工具（TypeScript AST 白名单计算），纯文本模式直接提交演示答卷。
3. 输入 `/results`，用 `m` 切换两套成绩。查看原始得分、题型和学科分项、待复核覆盖和运行指标。作答文本和模型用量由本地脚本模拟，运行用时和工具状态来自实际执行。
4. 输入 `/review`。主观题待人工评分，按 `1`、`2`、`3` 分别查看题面、答卷和评分依据。按 `s` 填分、`c` 填确认人、`e` 填理由，按 Enter 检查后用 `y` 保存。另一模式可在 `/tasks` 选中对应记录后复核。
5. 在运行中按 `s` 停止，等待记录保存。用 `/tasks` 按作答模式找到对应记录，再按 `v` 查看续跑计划。续跑保留已完成答卷，继续未开始的题目。正在作答时被中断的题目保留原状态。要重新体验整个流程，可将原样题包作为新版本导入，例如填写题集版本 `2`。

演示题面与原图须保持原样。草稿、题集版本、工具工作目录和任务记录均写到 `.work/offline-demo/`。整个流程无需模型接口或 Python 环境。
